



public
所有在區塊裡的變量預設是"隱形"的，public想當於將它"現形"，使其可見；

static
相當於將物件變為公眾物品，大家都可用。
class box{...}                                     //老師的箱子
class box{...public pens...}               //老師的箱子，告訴你裡面有筆，但其他的物件不讓你知道，仍為"私隱"，只讓你知道有"筆"，且沒說給大家用，屬老師私人物品；
class box{...public static pens...}    //老師的箱子，裡面的筆說了可免費給同學隨便用。但箱子是老師私人物品，她沒同意你能私自打開，所以筆大家還是不能用；
class static box{...public static pens...}    //老師的箱子，說了大家可以隨便打開，裡面的筆也可以隨便用。但，其他沒聲明static的不能用，只能用筆；
class static box{...public pens...}    //老師的箱子，說了大家可以隨便打開，裡面的東西只告訴你有筆，其他的藏暗格，筆也沒說能用；
