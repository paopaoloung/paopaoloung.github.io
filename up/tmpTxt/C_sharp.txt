namespace ≈ 開新资料夹
class ≈ 软件安装包/zip ——office/PS
object ≈ 解压后实际软件——readme.txt/word.exe/setting.ini等

static（靜態）--想成：全体共用的屬性
标识符就是你给程序里的东西起的名字；
  • 不能与class同名；
  • 不能使用關鍵詞，除非加@；if✖️，@if✔️


float  ≈ 普通小数（約小數點後7位）
double ≈ 更精确的小数（可存15-16位）

string str = @"C:\Windows";
[@:逐字字符串-引號里的全為字符，包括空格/換行]

string str = "C:\\Windows";
[\:轉義符 將\原文輸出]


string s = @"我说""你好""";
[相當于：我说"你好"，双引号特殊，要2个]


int a = 10;
&a：房子的门牌号码（内存地址）可能是--地址1000 → [10]
int *p = &a; [数据类型 * ——指针]
  • 将p指向a的内存位置
  • 售楼中介p找到房子主人a
