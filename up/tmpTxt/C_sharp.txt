int a = 10;
&a：房子的门牌号码（内存地址）可能是--地址1000 → [10]
int* p = &a; [数据类型 * ——指针]
  • 将p指向a的内存位置[1000]
  • p：售楼中介p找到房子主人a的房子
  • *p：售楼中介取得房子a[&a]待售

—————————————————————
void change(int* p)  //改一个内存地址
{
  *p = 100;  //任何扔进去的数值都变为100
}

int a = 10;
change(&a);  //把a的内存地址扔进去更改

char和string区别？
char：单个字符；string：字符串（一段文字）
char c = 'A';
string s = "A";
看起来一样，但实际上不同：
  •'A' → 一个字符
  •"A" → 长度为 1 的字符串

char   = 一颗珠子
string = 一串珠子，它仍然是一串珠子，只是里面只有一颗。
